#+TITLE: Sp1NY: the key algorithms
#+OPTIONS: toc:nil num:nil

Sp1NY shows a speech recording, what is computed from it, and its annotations, and stays interactive on long
recordings. These documents explain how, by category and by plugin. The common idea is that *only what can be seen is
computed or kept at full precision*: the screen has far fewer columns than a recording has samples.

* Reproducing

=assets/make_diagrams.py= generates the figures. =scripts/gen_data.py= generates long recordings with dense annotations,
and =scripts/bench.py= measures the duration and the memory of a typical session on them:

#+begin_src sh
python docs/scripts/gen_data.py /tmp/spiny-data long 600
BENCH_NO_WAVELET=1 python docs/scripts/bench.py /tmp/spiny-data long
#+end_src
